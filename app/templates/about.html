About This Project

The Diabetes Prediction System is a Machine Learning web application developed using the Pima Indians Diabetes Dataset.

Project Features

  • Predict diabetes risk using Machine Learning.
  • Display prediction confidence.
  • Store prediction history in SQLite.
  • View all previous predictions.
  • Simple and user-friendly web interface.

Technology Stack

  • Python
  • Flask
  • Scikit-learn
  • SQLite
  • HTML & CSS


How It Works

Diabetes Prediction AI uses a trained Machine Learning model to analyze health-related input values and estimate the risk of diabetes.

Prediction Process

  1. Enter the patient's health information.
  2. The Machine Learning model processes the input.
  3. The application generates a diabetes risk prediction.
  4. The prediction confidence is displayed to the user.
  5. The prediction can be stored and reviewed in history.
